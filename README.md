# John Khan

**I build data tools for Canadian borrowers, homeowners and lenders.** Toronto, Ontario.

[![LinkedIn](https://img.shields.io/badge/LinkedIn-johnmortgages-011F5B?style=flat-square&logo=linkedin&logoColor=white)](https://www.linkedin.com/in/johnmortgages/) [![Kaggle](https://img.shields.io/badge/Kaggle-johnnykhan1-011F5B?style=flat-square&logo=kaggle&logoColor=white)](https://www.kaggle.com/johnnykhan1) [![Website](https://img.shields.io/badge/website-john--khan--site-990000?style=flat-square)](https://alenzacodes.github.io/john-khan-site/)

I've spent many years in financial services, including mortgages, business lending and alternative investments. I work in Canadian mortgage finance, and I build tools for the points where files stall: a missing document, a ratio that fails at the qualifying rate, a renewal signed without a comparison. Everything below runs in the browser, uses public data from the Bank of Canada, Statistics Canada, CMHC and OSFI, and links to its sources.
